# 올해의 밈 투표와 밈 테스트 기획

[SNS 공유 카드 시안](meme-worldcup-share-card-ideas-v1.html)

## 올해의 밈 투표

1. 홈에서 **올해의 밈 투표**를 누르면 후보 목록을 보여준다.
2. 가장 인상 깊었거나 가장 자주 썼던 밈 하나를 골라 한 표를 던진다.
3. 투표가 끝나면 밈 이름과 대표 이미지를 담은 **내가 뽑은 올해의 밈** 카드를 보여준다. 영상 밈은 썸네일이나 대표 장면을 사용한다.
4. 카드에 **너는 뭐 뽑았어?**를 넣는다. 참여 링크를 열면 공유자가 고른 밈을 먼저 보여주고, 후보 목록으로 이어진다.

## 내가 아는 밈 테스트

1. 홈에서 **내가 아는 밈 테스트**를 누르면 2026년 밈 20개를 한 장씩 보여준다.
2. 질문은 **이 밈 알아?**로 통일한다. 답변 버튼은 **O 안다**와 **X 모른다**로 표시하고, 선택하면 다음 카드로 넘어간다. 정답을 맞히는 퀴즈와 달리 사용자가 알아본 밈을 직접 체크하는 방식이다.
3. 결과에는 **알아본 밈 개수 / 20**, 해당 등급, **너는 몇 개 알아?**를 보여준다.
4. 공유 링크를 열면 같은 20개로 테스트한다. 완료 후 **친구 17개 · 나 14개**처럼 두 결과를 나란히 보여준다.

### 결과 등급

| 알아본 밈 | 등급 |
| --- | --- |
| 20개 | 커뮤니티 망령 |
| 15~19개 | 커뮤니티 망력 |
| 10~14개 | 미정 |
| 5~9개 | 미정 |
| 0~4개 | 늙크크를 넘어선 올크크 |

## SNS 공유

- 두 결과 화면에서 **스토리 이미지 저장**과 **참여 링크 복사**를 제공한다.
- 공유 이미지는 세로 9:16 카드로 만들고, 한눈에 읽히도록 투표는 고른 밈을, 테스트는 점수와 등급을 크게 표시한다.
