## 쇼츠 플레이어 규칙

- 각 밈에 사진 또는 쇼츠 영상 한 개를 연결하고, 갤러리에 지정된 순서대로 보여준다.
- 갤러리에 처음 진입했을 때 첫 카드가 영상이면 카드 안에서 무음으로 자동재생된다.
- 스와이프나 화살표 등으로 밈을 넘기면 이전 카드의 영상은 일시정지한다. 새 카드가 사진이면 사진을 보여주고, 영상이면 처음부터 재생한다. 이전 영상 카드로 돌아와도 처음부터 재생한다.
- 사용자가 **소리 켜기**를 누르면 현재 영상의 소리를 켜고, 사진을 거쳐도 다음 영상에 소리 설정을 이어간다.
- 브라우저가 소리 있는 자동재생을 막으면 무음으로 다시 시도한다. 무음 자동재생도 막히면 사용자가 **재생** 버튼을 눌러 시작할 수 있다.
